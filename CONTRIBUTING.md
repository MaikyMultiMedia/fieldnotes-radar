# Collaboration

Use an issue to describe the user problem and an observable expected result. Make a feature branch (for example `codex/compact-alert-cards`), edit, run tests and submit a pull request to `main`. A coding assistant can follow AGENTS.md from any editor.

For navigation changes, inspect desktop and 390px layouts. For a signal rule, test boundaries, missing data, duplicate observations, wrong contracts/pools, stale data and historical timing. For privacy changes, verify direct requests cannot return data or credentials; hiding a UI element is not sufficient.

The public preview has no accounts or private user state. A future personalized service needs authentication and per-user authorization before collecting portfolios. Do not add a cosmetic login button that suggests protection which does not exist.

An owner must invite collaborators by exact GitHub username. Do not share GitHub tokens or API keys. Forks/pull requests are also available for public source collaboration. Hosting publishes only `site/`, never the repository or database directory wholesale.

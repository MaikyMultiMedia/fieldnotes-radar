# Working on Fieldnotes

This repository is the isolated public edition. Keep it separate from ASTRA, avatar, Blender, Godot, SAGA and private portfolio projects.

- Read README.md and DATA_ACCESS.md before changing data access.
- Never add wallet histories, screenshots, real user positions, keys, cookies or private database exports.
- Synthetic fixtures must be prominently labeled. Never present demos as live observations.
- No trading, wallet signing, private endpoint reverse engineering, or Fomo scraping.
- Do not enable public provider-data redistribution without documented permission.
- Unknown, stale and zero are distinct. Match tokens by exact contract, chain and pool, never ticker alone.
- Prefer small vanilla-JS/Python changes; avoid adding a framework without a concrete benefit.
- Check mobile navigation and keyboard accessibility. Reduced motion must be respected.
- Run `python -m unittest discover -s tests -v` and `node --check site/app.js`.
- Describe changes and actual validation in pull requests. No unrelated project integration.
